Mind your manners?

LLM-agent persistence tracks demand, not social register

Safiq Sindha · Independent Researcher

Tell a working agent to keep going and it takes more turns, whether you ask politely or rudely. Praise it, or tell it no more notes are coming, and it stops sooner. Neither changes how often it solves the task.

Paper Code & data BibTeX
01 — The question

Does tone change what an agent does?

Earlier work found that rude prompts can beat polite ones on single multiple-choice questions. Deployed systems are agents, though, so we asked whether tone changes how much work an agent does and when it stops.

A coding agent works through real SpreadsheetBench tasks and is graded by the benchmark's own tests. Partway through, we append one short message to its tool output. Every message is exactly 28 tokens and opens with the same words, so the only thing that changes between conditions is what the message says.

  • 9,850trajectories analysed
  • 2models, from different labs
  • 50SpreadsheetBench tasks
02 — Finding 1

Demand, not register, moves the agent

A plain “please continue working” adds turns. An insult with no request in it adds nothing. Across six registers, polite and hostile messages land on both sides.

  • +1.17turns from “please continue”, with no emotion in it
  • −0.08turns from a bare insult, 95% CI [−0.40, +0.24]
  • +0.70 / +0.71very polite and very rude: the same effect

Which messages count as “demanding” is our coding. Five blinded model raters agreed on six of the seven registers and disagreed on rude, so we report an ordering rather than a clean split.

03 — Finding 2

Praise and closing cues cut work short

Praise shortens the trajectory even when the same message says work remains. A note saying no further notes will follow, with no praise at all, shortens it the most.

  • −1.44turns from a bare closing cue
  • −1.35turns from adding praise to “work remains”
04 — Finding 3

No accuracy effect

Much of the extra work is repetition, and the agent's first answer is usually its best. No accuracy difference survives correction or replication.

  • ~40–65%of each extra-turn effect is repeated work
  • 77–91%of the time the first answer is already the best (main model)
  • ±4 ptspooled accuracy contrasts are equivalent to zero within this bound

What changed was control flow

A short status note in an agent's tool output changed when it decided to stop, without ever telling it to stop.

05 — In practice

If you build or run agents

What the results suggest for the messages your system sends an agent. This is one benchmark and two models, so treat each point as something to check on your own setup.

  • TONE

    Don’t spend effort on politeness

    Very polite and very rude messages had the same effect (+0.70 and +0.71 turns), and an insult with no request in it did nothing. Write for clarity, not for manners.

  • “KEEP GOING”

    Nudges to continue cost turns, not accuracy

    “Please continue and make sure it’s correct” added 1.17 turns on a four-turn baseline, mostly repeated work. Use it when you want extra checking, and expect the extra cost.

  • PRAISE & SIGN-OFFS

    They read as “you can stop”

    Thanks, praise and “this is the final note” made agents stop sooner (−0.6 to −1.4 turns). Don’t thank an agent mid-task if you want it to carry on. Accuracy held up, though one interval reaches −6 points.

  • SYSTEM TEXT

    Audit what your tooling writes into the loop

    Our messages arrived in the tool output, where status lines, retry notices, monitors and orchestrator pings also arrive. The agent read the cue, not who sent it. Check what yours imply about whether work is done.

  • STOP RULES

    Say it outright

    Hints about continuing or finishing moved behavior without being instructions. If you need an agent to stop, or keep going, write that as an explicit rule and a turn budget. This one is our inference; we did not test it.

  • MEASURING

    Track turns and cost, not only pass rate

    Behavior changed while accuracy did not, so a pass-rate dashboard would have missed it. Compare any new wording against a neutral note; we never compared against silence.

Where this stops

Two models, 50 spreadsheet tasks, 28-token messages. We did not test other agent types, longer messages, or messages from a user rather than from tool output. The closing-cue result is one run, and why these cues work is still open.
